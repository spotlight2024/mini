# Selenium Grid 部署检查清单

## 📋 部署前检查

### 环境检查
- [ ] Kubernetes 集群版本 >= 1.20
- [ ] kubectl 已安装并配置
- [ ] Helm 3.0+ 已安装
- [ ] 集群节点资源充足（建议至少 4GB RAM，2 CPU）
- [ ] 网络连通性正常
- [ ] 镜像仓库可访问

### 镜像准备
- [ ] `selenium/hub:latest` 镜像已拉取
- [ ] `chrome-tinyproxy-node:latest` 镜像已拉取
- [ ] `busybox:1.36` 镜像已拉取（用于测试）

## 🚀 部署步骤

### 1. 基础部署
- [ ] 进入工作目录：`cd mini/docker/k8s`
- [ ] 检查脚本权限：`ls -la *.sh`
- [ ] 运行一键部署：`./quick-deploy.sh`

### 2. 部署验证
- [ ] 检查命名空间：`kubectl get ns selenium-grid`
- [ ] 检查 Pod 状态：`kubectl -n selenium-grid get pods`
- [ ] 检查服务状态：`kubectl -n selenium-grid get svc`
- [ ] 检查扩容配置：`kubectl -n selenium-grid get scaledobject`

### 3. 功能测试
- [ ] 访问 Hub Web UI：http://172.16.1.129:30444
- [ ] 运行扩容测试：`python3 test_scaling.py`
- [ ] 检查扩容日志：`kubectl -n selenium-grid logs -f deploy/grid-metrics-exporter`
- [ ] 验证代理功能（IP 检查）

### 服务状态
