# 数据采集模块说明

本目录包含数据采集相关的功能说明和文档。

## 功能概述

数据采集模块负责从Android虚拟机中采集各种数据，包括：
- 页面元素信息
- 用户交互数据
- 系统状态信息
- 性能监控数据
