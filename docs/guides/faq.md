# FAQ - 常见问题

## 1. 设备连接失败
- 检查ADB连接状态
- 验证设备序列号
- 确认网络连通性

## 2. WebDriver初始化失败
- 检查Chrome/Chromium安装
- 验证ChromeDriver版本
- 确认端口占用情况
- 检查Appium Server状态（如使用Appium）

## 3. 操作执行超时
- 检查网络延迟
- 验证元素定位器
- 确认页面加载状态

## 4. 虚拟环境相关问题
- 每次运行项目前需激活虚拟环境
- 安装新依赖时确保虚拟环境已激活
- 如遇模块导入错误，检查PYTHONPATH或重新安装项目包

## 5. 其它
- 详细问题请参考[主项目README](../../README.md)或联系维护者。
