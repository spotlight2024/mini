# 创建 PR

## 概览
创建一个结构清晰的拉取请求，包含合适的描述、标签和评审人。

## 步骤
1. **准备分支**
   - 确保所有更改已提交
   - 将分支推送到远程仓库
   - 确认分支已与 main 同步

2. **撰写 PR 描述**
   - 清晰总结更改
   - 说明背景与动机
   - 列出任何不兼容性变更
   - 如有 UI 变更，附上截图

3. **设置 PR**
   - 使用有描述性的标题创建 PR
   - 添加合适的标签
   - 指定评审人
   - 关联相关 issue

## PR 模板
- [ ] 功能 A
- [ ] 缺陷修复 B
- [ ] 单元测试通过
- [ ] 手动测试完成
